# המשימות שלי

מערכת ניהול משימות בעברית (RTL) עם סוכן AI מובנה.

- **מרחבים** עם צבע ותצוגה לבחירה: קנבן (גרירה בין עמודות), רשימת TODO לפי עדיפות, ולוח שנה חודשי. אפשר להחליף תצוגה בכל רגע.
- **דשבורד**: בחירת מרחבים (נשמרת), משימות דחופות / להיום / באיחור, וכרטיס סיכום לכל מרחב.
- **סוכן**: צ'אט צף עם חמישה כלים (קריאה, הוספה, עדכון, מחיקה, סיכום). פועל רק על הטווח שנבחר, ומבקש אישור לפני מחיקה או שינוי של יותר מ-3 משימות.

## טכנולוגיה

Next.js (App Router) · TypeScript · Tailwind · Postgres (`pg`) · OpenAI API.

## הרצה מקומית

```bash
npm install
cp .env.example .env   # ממלאים DATABASE_URL, OPENAI_API_KEY, APP_PASSWORD
npm run dev
```

הטבלאות נוצרות אוטומטית בבקשה הראשונה. נתוני דוגמה: אחרי כניסה, `POST /api/seed` (מוסיף רק אם המסד ריק; `{"reset":true}` מאפס).

## משתני סביבה

| משתנה | תיאור |
|---|---|
| `DATABASE_URL` | חיבור ל-Postgres |
| `OPENAI_API_KEY` | מפתח OpenAI |
| `APP_PASSWORD` | הסיסמה היחידה לכניסה |
| `OPENAI_MODEL` | אופציונלי. ברירת מחדל `gpt-6-luna` |

## איך הסוכן בנוי

- `lib/agent.ts` - לולאת כלים מול OpenAI. כל כלי מסונן לפי הטווח שנשלח עם ההודעה, בצד השרת.
- פעולה שדורשת אישור לא מתבצעת. היא נשמרת בטבלת `pending_actions`, והצ'אט מציג כפתורי מאשר / לא מאשר. הביצוע קורה רק ב-`/api/agent/confirm`.
